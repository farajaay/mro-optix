# MRO Optix Individual v2.1

MRO Optix is an English Excel workflow for a bounded turnaround material review. It keeps requested, proposed, and engineering-approved quantities separate and distinguishes usable stock, on-time purchase orders, late purchase orders, and additional purchase need.

**Current status:** Candidate release. Sales are closed while native Microsoft 365 Excel for Windows acceptance, worksheet-protection validation, seller verification, and delivery testing are pending.

## Individual edition scope

- Planned launch price: USD 299, one time
- One named user, one organisation, one named industrial site
- 250 request lines
- 500 master-data, 500 material/plant history, and 500 BOM records
- Eight comparable event slots per material/plant
- One open-PO quantity and due date per material/plant
- No live ERP integration or automatic engineering approval

Proposed quantity changes are review outputs. They are not approved quantities, realised savings, or guarantees. Fictional demonstrations are not customer results.
